# Ricoh GR Shutdown Covers

[English](README.md) · [简体中文](README.zh-CN.md)

Unofficial shutdown-screen cover artwork for Ricoh GR cameras. The collection includes anniversary designs, diary-style linen covers, street-style asphalt covers, and a GR II compatibility set.

## Contents

- `GR关机封面（默认gr2尺寸）/` — main high-resolution collection. Most images are 4:3; exact pixel dimensions vary by file.
- `GR关机封面（gr2适配版）/` — JPEG compatibility collection for GR II. The project owner recommends this folder for GR II to reduce image-reading compatibility issues. Most files are 640 × 480; check individual files because a small number use a different size.
- Styles include anniversary, linen diary, asphalt street, and hammer-tone limited-edition designs.

## Anniversary artwork and attribution

- **10th anniversary:** a fan-made recreation based on a real-camera photograph shown in Ricoh's official news material.
- **20th anniversary:** an official image supplied by Ricoh, alongside an adjusted version for the collection. The original artwork and marks remain the property of their respective rights holders.
- **30th anniversary:** fan-made compositions drawing on the 10th- and 20th-anniversary cover designs and official anniversary branding. These are unofficial derivative designs.

## Aspect ratio and camera fit

The collection's default artwork is generally 4:3. The project owner's stated display sizes are **640 × 480 (4:3) for GR II** and **720 × 480 (3:2) for GR III / GR IV**. The GR II-compatible folder is recommended for GR II. The repository does not provide a separate complete 720 × 480 export set; select a suitable image and confirm the camera accepts its dimensions and format before use.

## Use

Choose the image that matches your camera model and preferred aspect ratio. Follow the camera's official instructions for registering a shutdown screen. This repository provides image files only; it does not modify camera firmware.
